# Accutar Biotechnology

> Accutar Biotechnology Inc. is a clinical-stage biotechnology company in Cranbury, New
> Jersey (founded 2015, previously Brooklyn, New York, with operations in Shanghai) that
> applies deep learning to small-molecule drug discovery and runs its own oncology
> pipeline. Its AI platform is a set of in-house products — ChemiRise, Orbital, Virtual
> Screen, Intelligent-SAR, Chemi-Net and the PatentOne AI suite — used in its own
> preclinical workflow and offered to partners by email enquiry. Accutar publishes no
> public API, developer portal, reference documentation, machine-readable specification
> or SDK on any host it operates. This file is generated by API Evangelist from public
> sources; it is not published by Accutar Biotechnology.

## API surface

- None published. As of 2026-09-06 there is no public API, no developer portal, no API
  reference, no OpenAPI/Swagger/GraphQL/AsyncAPI document, no webhook catalog, no MCP
  server, no A2A agent card, no `/.well-known/` discovery document, no `llms.txt`, no
  client SDK, no CLI and no Postman collection on any Accutar host.
- `api.accutarbio.com`, `docs.accutarbio.com`, `developer.accutarbio.com` and
  `app.accutarbio.com` do not resolve in DNS.
- The only machine-readable interface served by `www.accutarbio.com` is the stock
  WordPress REST API at `/wp-json/`, which belongs to the CMS running the marketing site,
  not to Accutar as a product. It is deliberately not registered as an Accutar API.

## AI products (access is by email enquiry, not by API)

- [ChemiRise](https://www.accutarbio.com/chemirise/): data-driven retrosynthesis engine
  trained on a patent database of over 3 million organic reactions. The product domain
  `chemirise.com` redirects to `www.chemirise.com`, which does not serve.
- [Orbital](https://www.accutarbio.com/products/orbital/): deep neural network docking
  platform, including apo-to-holo structure prediction.
- [Virtual Screen](https://www.accutarbio.com/products/virtual-screen/): virtual screening
  across more than 10 million compounds.
- [Intelligent-SAR](https://www.accutarbio.com/intelligent-sar/): lead optimization.
- [Chemi-Net](https://www.accutarbio.com/chemi-net/): molecular graph convolutional network
  for ADME property prediction.
- [InsightOne](https://www.accutarbio.com/insightone/): AI patent metadata extraction.
  Trial or demo by email to demoinsightone@accutarbio.com.
- [GenusOne](https://www.accutarbio.com/genusone/): web-based cheminformatics tool for
  Markush genus patent claim drafting, exporting Word and ChemDraw-compatible output.
  Trial or demo by email to bd@accutarbio.com.
- [PinkCare.AI](https://www.accutarbio.com/pinkcare/): patient-facing health question
  assistant. The page links its chat surface at `https://chat.pinkcare.ai`, but neither
  `pinkcare.ai` nor `chat.pinkcare.ai` resolves in DNS.
